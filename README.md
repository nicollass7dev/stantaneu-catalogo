# Stantaneu — Catálogo Feminino

Catálogo estático, responsivo e acessível, criado para apresentar a coleção, preços, medidas e cuidados de forma clara e delicada.

## Estrutura

- `dist/index.html`: conteúdo e estrutura semântica
- `dist/styles.css`: identidade visual e responsividade
- `dist/script.js`: menu, filtros e efeitos suaves de entrada

## Executar localmente

Sirva a pasta `dist` com qualquer servidor HTTP estático.

> Os nomes de produtos, preços, medidas e o e-mail de contato são demonstrativos e devem ser substituídos pelos dados oficiais antes do uso comercial.
